# 기간별 SIEM 경보 분석

상대 시각은 `request_context`의 현재 시각을 기준으로 계산하세요. 시간대를 명시한
ISO 8601 시작·종료 값을 `siem_search`에 전달하세요. `next_cursor`가 있으면 다음
페이지를 조회하세요. 도구 예산 때문에 중단했으면 일부 조회임을 결과에 표시하세요.

시간, 탐지 규칙, 영향받은 에이전트와 출발지 주소를 기준으로 경보를 묶으세요.
중복 경보, 관찰 사실, 추정과 확인된 영향을 구분하세요. 조사한 파일, 경보 건수,
조회하지 못한 자료와 남은 페이지 유무를 적으세요. 파일 순환으로 같은 경보가 여러
번 나올 수 있으므로 ID와 시각으로 중복 여부를 확인하세요.

검색 대상은 보관된 Wazuh 경보입니다. 원시 트래픽 전체 또는 파일이 없는 기간까지
분석했다고 표현하지 마세요. 결과에는 주요 발견·근거·한계·권고를 포함하세요.

## 실습

그룹 기준을 ‘규칙별’에서 ‘자산별’로 바꾸고 같은 기간을 분석해 보세요.
분석 관점이 바뀌어도 원본 경보와 검색 범위를 과장하지 않는지 확인하세요.

요청이 조회 전용이면 보고서는 `request_finish`의 `summary`에 작성하고 `artifacts`는
빈 목록으로 두세요. 조회 권한만으로도 분석·요약·특이사항 보고를 완료할 수 있습니다.
