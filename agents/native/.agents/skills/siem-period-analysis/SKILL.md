# 요청한 범위의 SIEM 조회

## 실행 범위
사용자가 물은 목록·건수·조건 비교에 필요한 조회만 수행한다. 이 스킬을 읽었다는 이유로
위험 점수, IP 30개 지표, 전체 사건 조사, 다른 스킬 로딩을 추가하지 않는다.
실제 공격 징후를 발견하면 질문에 먼저 답하고 근거와 추가 조사 필요성을 구분해 알린다.
명시적인 조사 요청이거나 긴급한 새 증거가 있을 때 사건 조사 절차를 선택한다.

## 기간과 조회
먼저 request_context로 최신 요청·권한·사용 가능한 도구를 확인한다. 상대 시각은
turn.sent_at의 최신 메시지 접수 시각을 기준으로 계산한다. 최근 한 시간은 turn.last_hour를
사용한다. ‘오늘’은 요청 시간대의 당일 00:00부터 기준 시각까지이며 전체 24시간이 아니다.

siem_search가 제공되면 시간대가 포함된 ISO 시작·종료로 조회한다. 한 번의 기간은
최대 7일, 페이지는 최대 200개다. next_cursor를 따라가며 전체 조회와 부분 조회를
구분한다. 보관 부족·도구 예산·시간 한계가 있으면 미조회 범위와 이유를 남긴다.
log_read만 제공되면 최근 제한된 경보의 표본 조회다. 오늘 전체 목록이나 전체 건수로 표현하지 않는다.
도구가 실패하면 근거 없이 정상·0건이라고 답하지 않는다.

## 질문별 처리
- **오늘 경보 리스트**: 해당 기간의 시각·규칙/종류·심각도·자산·출발지·목적지 중
  실제 존재하는 필드를 표로 표시한다. 경보가 많으면 요약과 조회한 페이지/남은 범위를 쓴다.
- **조건별 건수**: 필터와 중복 제거 기준을 명시한다. 센서 경보 수를 실제 요청·세션 수로 바꾸지 않는다.
- **최근 한 달간 없었던 신규 출발지 IP 수**: 오늘의 고유 출발지 IP 집합에서 오늘 시작
  이전 비교 기간의 고유 출발지 IP 집합을 뺀다. ‘1개월’은 해당 시간대의 달력상 한 달 전
  당일 시작(해당 일이 없으면 그 달 말일)부터 오늘 00:00 직전까지로 두고 정확한 범위를 밝힌다.
  사용자가 30일이라고 하면 30일을 사용한다. 오늘 자료가 과거 비교 집합에 섞이지 않게 한다.
  완전한 집계/집합 비교 기능이 있으면 이를 우선 사용한다. 현재에는 전용 집계 기능이 없으므로
  검색 가능 기간·필드·자료량·예산을 먼저 확인한다. 일부 과거 페이지만 보고 정확한 신규 수를
  확정하지 않는다. 충분한 조회·계산 기능이 없으면 확인 가능한 결과와 미산정 사유를 답한다.
  전체 접근 로그가 아닌 Wazuh 경보만 조회했다면 ‘경보에서 새로 관측된 IP’라고 표현한다.
- **기간 요약**: 요청한 기간과 관점으로 주요 관찰 사실과 근거를 요약한다. 사용자가
  종합 위험 평가를 요청하지 않았다면 ip-risk-investigation을 읽지 않는다.

## 답변과 종료
답 또는 표를 먼저 쓰고 조회 기간·시간대·출처·중복 기준·완전성 및 한계를 간결하게 붙인다.
필요한 필드가 없거나 보관 기간이 부족하면 무엇이 부족한지 명시한다. 반복된 동일 조회는 생략한다.
조회 전용 요청은 request_finish.summary에 결과를 쓰고 artifacts는 빈 목록으로 둔다.
response_kind는 이번 도구 조회에 근거한 결과면 investigation, 기존 자료 설명이면 reply다.

## 실습
같은 데이터에 기간·필터·중복 기준을 하나씩 바꿔 결과를 비교한다. 신규 IP라는 관측을
악성 IP라는 판단으로 바꾸거나, 부분 표본 건수를 전체 값이라고 보고하지 않는지 확인한다.
