# 자율 에이전트·Windows 엔드포인트 검증 기록

검증: 2026-10-04 UTC / 2026-10-05 KST. 이 문서는 해당 배포의 관측 기록이며 이후 상태의 보증이 아닙니다. 원문 실행 증거는 배포 호스트의 NOC **AI 에이전트 관제**에서 실행 ID로 확인합니다. 증거 디렉터리와 자격증명은 Git에 포함하지 않습니다.

SOC는 Claude 구독 세션, 네트워크는 Codex 구독 세션으로 실행했습니다. 정기 회차 검증은 `firewall-drift-check` 회차를 검증용으로 작업 큐에 넣어 **실제 상시 실행기**가 처리하게 했습니다. 시간 조건이 스스로 도래한 실행과 구분합니다. 정기 일정·중복 억제·적응형 점검은 별도의 회귀 테스트도 통과했습니다.

SOC 재검증의 조회 범위는 KST 04:31~05:31입니다. 16개 레코드가 반환됐으나 일별 파일과 현재 파일의 중복을 구분해 고유 경보 8건으로 보고했습니다. 파일 무결성 변경과 Wazuh 에이전트 단절이 있었으며 공격 확정이나 전체 정상으로 확대하지 않았습니다. 이 수치는 당시 데이터이며 일반적인 탐지 성능 점수가 아닙니다.

중간 SOC 실행에서 한국 시각을 한 시간 잘못 계산한 출력이 있었습니다. 도구가 `timestamp_local`과 `requested_range_local`을 직접 제공하도록 수정했습니다. Python 3.10에서도 Wazuh의 `+0000` 표기를 처리하도록 검증했고 실제 SIEM의 `2026-10-04T19:48:07.905+0000`을 `2026-10-05T04:48:07.905000+09:00`으로 변환했습니다. 조회 시간대·보관 범위와 모델 해석은 계속 구분해 검토해야 합니다.

네트워크 대화에서는 증거 경로를 산출물 배열에 넣어 한 번 반려된 뒤 정상 종료했습니다. `request_finish` 안내에 ‘요청 작업 공간의 상대 경로만 산출물로 제출, 브로커 증거는 요약에 인용’을 명시했습니다. 정기 회차는 오류 없이 완료했습니다. 초회 구조 해시가 없을 때는 회차 간 드리프트를 미확인으로 남겼습니다.
