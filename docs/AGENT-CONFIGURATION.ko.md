# 근무자 운영: 설정 파일·R&R·스킬 관리

[프로젝트 안내](../README.md) · [교수·강사용 매뉴얼](INSTRUCTOR-GUIDE.ko.md) · [학생용 SOC 실습](STUDENT-GUIDE.ko.md#agent-learning)

NOC의 **근무자 운영**은 `agents/` 원본을 직접 읽고 수정하는 화면입니다. 별도 DB에 역할을 복제하지 않습니다. 저장 전에는 임시 사본에서 실제 하네스 컴파일러로 확인하고, 저장 후 Claude/Codex 실행 사본과 활성 버전을 생성합니다. 설정 저장 자체가 AI 세션을 실행하지는 않습니다.

## 화면과 파일의 대응

아래 경로의 기준은 `agents/`입니다.

| 화면 | 원본 | 설정 내용 |
|---|---|---|
| 1 회사 | `company.yaml` | 목표·우선순위·운영 원칙 |
| 2 조직 | `departments.yaml` | 부서 책임·제외 업무·에스컬레이션 |
| 3 팀 | `teams.yaml` | 구성원·KPI·협업 지표 |
| 4 근무자·R&R | `roster.yaml` | 주 소속·런타임·모델·직무·자율성·루프·담당 자산 |
| 4 → R&R·스킬·담당 설정 | `personas/<id>.md`, `roster.yaml` | 역할·업무 경계·협업·보고·스킬 연결·담당 범위 |
| 5 일하는 방식 → 스킬 라이브러리 | `native/.agents/skills/<이름>/SKILL.md` | 상세 절차 추가·수정·삭제·근무자 연결 |
| 5 → 루프 | `loops/*.yaml` | 주기·담당자·트리거·업무 단계 |
| 5 → harness.yaml 직접 편집 | `harness.yaml` | 상속 정책·직무별 실제 접근 상한·예산·시간대 |
| 업무 요청 → 지침 실습 | `native/AGENTS.md`, 공통 역할·기존 스킬 | 사용자 업무 공통 지침 및 같은 스킬 원본 편집 |
| 6 적용 | `runtimes/activation.json`, 생성 manifest | 원본·적용 사본 대조, 재생성, 백업 복원 |

`graph/experience.json`은 팀의 경험 자료이며 하네스 지침과 별도입니다. `runtimes/`, `evidence/`, `tickets/`는 생성물·실행 증거·업무 상태입니다. 이를 지침 원본처럼 편집하지 않습니다. 새 루프 파일 생성, 스킬의 보조 스크립트·자료 파일 관리는 저장소에서 진행합니다. 스킬 화면은 `SKILL.md`를 관리합니다.

## 업무 R&R 설정

R&R은 **부서의 책임 → 팀의 목표 → 개인의 역할**로 구성됩니다.

1. **조직**에서 부서의 `mission`, `not_our_job`, `escalates_to`를 정합니다.
2. **팀**에서 구성원·KPI·협업 지표를 정합니다.
3. **근무자·R&R → 해당 근무자 → R&R·스킬·담당 설정**에서 역할 요약, 하는 일과 하지 않는 일, 협업·보고 기준을 작성합니다.
4. 연결 스킬·담당 루프·자산을 선택하고 **R&R·연결 저장**을 누릅니다.

상단에 주 소속 부서의 책임이 표시됩니다. ‘실제 컴파일러가 확인한 권한·원본’을 펼치면 상속 후 정책과 정기 업무 도구를 볼 수 있습니다. 사용자 업무에는 배정 기능·조회 범위·대화 승인 조건도 적용됩니다.

**역할 설명과 실제 권한은 구분합니다.** persona의 `tools`나 스킬 지침으로 권한을 늘릴 수 없습니다. `roster.assets`는 담당 자산 설명이며 실제 조회 범위는 보안 직무의 자산 정책과 도구가 결정합니다. 네트워크 담당에게 시스템 스킬을 연결해도 디스크 조회 권한이 생기지 않습니다.

현재 컴파일러는 `roster.team`의 **주 소속 팀·부서**를 전달합니다. 다른 팀의 `members`에도 참여한다고 그 팀의 KPI 전체가 자동 병합되지는 않습니다.

## 스킬 추가·연결

1. 오른쪽 위에 강사 키를 입력합니다.
2. **일하는 방식 → + 스킬 추가**를 누릅니다.
3. 이름은 `soc-monthly-review`처럼 소문자·숫자·하이픈으로 정합니다. 폴더 이름과 머리말의 `name`은 같아야 합니다.
4. `description`에는 **언제 선택하는 절차인지**, 본문에는 입력·범위·작업 순서·판단·협업·결과 기준을 한국어로 작성합니다.
5. 저장한 카드의 **근무자에 연결**을 누르고 담당 근무자의 **R&R·스킬·담당 설정**을 엽니다.
6. 스킬 선택을 확인하고 역할 본문에 선택 기준을 적은 뒤 **R&R·연결 저장**을 누릅니다.
7. 새 대화·업무에서 `skill_read` 기록과 산출물을 확인합니다.

SOC 월간 분석이라면 “명시적인 월간 분석 요청에 이 스킬을 읽는다”는 선택 기준을 역할에 추가합니다. 기존 조회·사건 조사·일일 보고 스킬은 유지합니다. [기본값과 월간 분석 예시](STUDENT-GUIDE.ko.md#soc-extensions)를 참고하세요.

스킬 연결은 자동 예약을 추가하지 않습니다. 예약하려면 루프 파일을 만들고 `owner`와 해당 근무자의 `loops`를 연결합니다. 화면에서는 다른 근무자가 소유한 루프를 선택할 수 없습니다. 담당자를 바꾸려면 기존 연결 해제 → 루프 owner 수정 → 새 근무자 연결 순서로 진행합니다.

## 수정·삭제·복원

- **수정:** 카드의 **원문 편집**에서 저장합니다. 업무 요청의 ‘지침 실습’도 같은 파일을 수정하고 적용합니다.
- **삭제:** 모든 근무자·보관 페르소나에서 연결을 해제한 뒤 삭제합니다. 실행기가 자동 사용하는 기본 스킬은 수정할 수 있지만 삭제할 수 없습니다. 삭제 대상은 해당 `SKILL.md`이며 보조 파일은 유지합니다.
- **복원:** **적용 → 되돌리기**에서 백업을 선택합니다. persona·루프·스킬의 원래 경로로 복원하고 검증·재적용합니다.
- **편집 충돌:** 스킬·R&R을 편집하는 동안 원본이 바뀌면 저장을 거부합니다. 수정 내용을 따로 보관하고 다시 불러옵니다. 기존 YAML 원문 편집기는 개별 충돌 감지가 없으므로 동시 편집을 피합니다.

실행 중인 업무가 끝난 뒤 편집합니다. 역할과 연결 스킬은 정책 버전에 포함되어 변경 시 기존 세션의 다음 도구 호출이 중단될 수 있습니다. 실행 당시의 불변 사본은 증거로 남습니다.

## 적용 확인

**적용 → 화면·원본·적용 상태 대조**에서 편집 위치, 연결 오류, 근무자별 원본과 적용 사본의 일치를 확인합니다. 파일·버전 정합성을 확인하는 검사이며, 모델이 지침대로 수행했다는 증명은 아닙니다. 실제 수행은 새 실행의 도구 기록과 결과로 확인합니다.

저장 전에는 누락 스킬, 런타임·모델 불일치, 잘못된 cron, 루프 소유자 불일치 등을 검사합니다. 자연어 기준의 품질이나 업무 수행 가능성까지 보장하지 않습니다. 적용이 대기 상태라면 원본 오류를 수정하고 **하네스 다시 생성**으로 포인터와 활성 버전을 갱신합니다.

스킬·R&R 조회/편집 API는 `X-API-Key` 인증을 사용합니다. 기존 강사 키이며 학생별 독립 권한 계정은 아닙니다.


## 연구소에서 설정을 개선하는 경로

5F 연구소는 기존 설정 편집 기능과 같은 원본을 사용합니다. `agents/research/sources.yaml`은 조사 출처와 연구 원칙, `agents/research/benchmarks.yaml`은 격리 평가 사례와 서버 채점 기준입니다. 학생은 자연어 업무 절차를 스킬 후보로 등록하고, 기준/후보 응답과 실제 토큰·시간을 비교할 수 있습니다.

후보는 `agents/tickets/research-lab/`에 보관하며 운영 스킬을 즉시 덮어쓰지 않습니다. 평가 통과 후 강사가 적용하면 `agents/native/.agents/skills/<이름>/SKILL.md`와 대상 persona의 `skills` 연결이 함께 변경되고 모든 실행 사본이 다시 컴파일됩니다. 정책이나 원본이 평가 이후 바뀌면 재평가해야 합니다. 적용 이후 다른 편집이 없다면 이전 상태로 복구할 수 있습니다.

`agents/xoc/rules.yaml`은 관제 규칙·가능성·영향·직무별 도구 기준선입니다. 자연어 persona는 역할과 판단 원칙, 이 규칙 파일은 코드 탐지 기준, `harness.yaml`은 서버가 강제하는 권한 상한입니다. 스킬 문구로 권한을 늘릴 수 없습니다. [전체 구조·실습 예시](AI-RESEARCH-XOC.ko.md)를 참고하세요.
