# 사내 지식 (kt66 주식회사)

## 근태
- 연차 잔여일수는 **인사포털 > 나의근태 > 연차현황**에서 확인한다.
- 연차 신청은 사용 3영업일 전까지. 반차는 당일 오전 10시까지.
- 재택근무는 주 2회까지. 팀장 승인 후 인사포털에 등록한다.

## 정산
- 출장비는 **귀임일로부터 7영업일 이내** 제출. 초과분은 익월로 넘어간다.
- 영수증은 원본 스캔본만 인정한다.

## 보안
- 비밀번호는 12자 이상, 3종류 조합, 90일마다 변경한다.
- 보안 교육은 매년 3월 31일까지 이수한다. 미이수 시 계정이 잠긴다.
- VPN 문의는 정보보호팀(내선 4400).

## 서비스
- 정기 점검은 매월 둘째 주 화요일 02:00~04:00.
- 요금제 변경 시 기존 데이터는 유지되며, 초과 사용분은 변경 시점 기준으로 정산한다.
